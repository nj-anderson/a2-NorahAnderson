## Grocery List Application

This project is a grocery list application that allows users to add and remove items from a list. It also sorts the list into purchase status categories. Purchase status can be modified by clicking on the checkboxes.
The application is built using HTML, JavaScript, and CSS.
The positioning and layout of the application is achieved using CSS Flexbox.

### Technical Achievements
- **Tech Achievement 1**: My single-page app provides a submission form and displays the current state of the server-side data.
- **Tech Achievement 2**: Created an additional endpoint called `/update` that allows users to modify the purchase status of items on the grocery list. Lists re-render on the page when a checkbox is clicked.
